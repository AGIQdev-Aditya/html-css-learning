# 🌐 HTML5 & Modern Web Engineering Mastery

A structured, foundational curriculum for Aditya to master modern HTML5 from first principles — built for real-world software engineering, AI interfaces, and academic excellence.

---

## 🎯 Philosophy

We don't just learn syntax to pass college exams; we learn **how the web actually works**.
* **Semantic over visual**: Understanding document structure for search engines, screen readers, and web crawlers.
* **Hands-on & muscle memory**: Writing every tag by hand with zero copy-pasting.
* **Live testing**: Real-time rendering with Live Server.

---

## 🗺️ Curriculum Roadmap

- [ ] **Day 01**: The HTML5 Skeleton, Document Anatomy, Headings, Paragraphs, Void tags (`<br>`, `<hr>`), Semantic formatting (`<strong>`, `<em>`, `<del>`, `<ins>`).
- [ ] **Day 02**: Hyperlinks (`<a>`), Relative vs. Absolute paths, Media (`<img>`, `<video>`, `<audio>`).
- [ ] **Day 03**: Lists (`<ul>`, `<ol>`, `<li>`), Complex Tables (`<table>`, `<tr>`, `<th>`, `<td>`, `rowspan`, `colspan`).
- [ ] **Day 04**: HTML Forms & User Input (`<form>`, `<input>`, `<select>`, `<textarea>`, `<button>`).
- [ ] **Day 05**: Modern Semantic Web (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`) & Final Capstone Project.
