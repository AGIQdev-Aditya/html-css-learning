## 🗺️ The 14-Day Master Curriculum

### 📦 PHASE 1: HTML5 DOCUMENT SKELETON & SEMANTICS (DAYS 01–05)
- [x] **Day 01 — Skeleton & Text Hierarchy:** `<!DOCTYPE>`, `<head>` vs `<body>`, `<meta>`, `<h1>`–`<h6>`, `<p>`, `<strong>` vs `<b>`, `<em>` vs `<i>`, void tags (`<br>`, `<hr>`).
- [x] **Day 02 — Links, Relative Paths & Media:** `<a>`, absolute vs relative paths (`./`, `../`), target attributes, `<img>` (alt text, aspect ratio), `<audio>`, `<video>`, security `rel="noopener"`.
- [x] **Day 03 — Lists & Complex Tables:** `<ul>`, `<ol>`, `<dl>`, `<table>`, `<tr>`, `<th>`, `<td>`, `colspan`, `rowspan`, `<thead>`, `<tbody>`, `<tfoot>`. (Major College Viva Topic).
- [x] **Day 04 — Forms & User Input:** `<form>`, `<input>` types (text, email, password, radio, checkbox, file), `<select>`, `<textarea>`, `<button>`, `<label for="">`, validations (`required`, `pattern`).
- [x] **Day 05 — Modern Semantic Architecture:** `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, Block vs. Inline elements (`<div>` vs `<span>`).

---

### 🎨 PHASE 2: CSS3 STYLING & MODERN VISUAL CRAFT (DAYS 06–11)
- [x] **Day 06 — CSS Selectors, Colors & Typography:** Inline vs Internal vs External CSS, specificity formula (`0, 1, 0, 0`), Hex/RGBA alpha channel, typography, Google Fonts.
- [x] **Day 07 — The CSS Box Model (The #1 Exam Trap):** `content`, `padding`, `border`, `margin`, vertical margin collapsing, `box-sizing: border-box` (The Universal Reset).
- [x] **Day 08 — Display & Positioning:** `display: block / inline / inline-block / none`, `position: static / relative / absolute / fixed / sticky`, `z-index` stacking context.
- [x] **Day 09 — Modern CSS Flexbox (The Superpower):** Main vs Cross axes, `justify-content`, `align-items`, `gap`, `flex-wrap`, centering a div in 2 lines, dynamic `flex-grow`.
- [x] **Day 10 — CSS Grid & Responsive Media Queries:** `display: grid`, `grid-template-columns`, `fr` units, `@media (max-width: 768px)`, viewport meta tag necessity.
- [x] **Day 11 — Visual Polish & Micro-Interactions:** `box-shadow` depth scale, `border-radius`, 60fps GPU-accelerated CSS transitions & transforms (`translateY`, `scale`), glassmorphism.

---

### 🚀 PHASE 3: CAPSTONE & PRODUCTION BENCHMARK (DAYS 12–14)
- [x] **Day 12 — Capstone Architecture & Wireframing:** Pure semantic HTML5 document skeleton for Aditya's developer portfolio & telemetry lab (zero div-soup).
- [x] **Day 13 — Capstone Responsive Styling:** Production CSS3 design system (variables, obsidian palette, Flexbox nav, Grid cards, responsive mobile reflow).
