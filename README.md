## 🗺️ The 14-Day Master Curriculum

### 📦 PHASE 1: HTML5 DOCUMENT SKELETON & SEMANTICS (DAYS 1–5)
- [x] **Day 01 — Skeleton & Text Hierarchy:** `<!DOCTYPE>`, `<head>` vs `<body>`, `<meta>`, `<h1>`–`<h6>`, `<p>`, `<strong>` vs `<b>`, `<em>` vs `<i>`, void tags (`<br>`, `<hr>`).
- [ ] **Day 02 — Links, Relative Paths & Media:** `<a>`, absolute vs relative paths (`./`, `../`), target attributes, `<img>` (alt text, aspect ratio), `<audio>`, `<video>`.
- [ ] **Day 03 — Lists & Complex Tables:** `<ul>`, `<ol>`, `<dl>`, `<table>`, `<tr>`, `<th>`, `<td>`, `colspan`, `rowspan`, `<thead>`, `<tbody>`. (Major College Viva Topic).
- [ ] **Day 04 — Forms & User Input:** `<form>`, `<input>` types (text, email, password, radio, checkbox, file), `<select>`, `<textarea>`, `<button>`, `<label for="">`, form validations (`required`, `pattern`).
- [ ] **Day 05 — Modern Semantic Architecture:** `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, Block vs. Inline elements (`<div>` vs `<span>`).

---

### 🎨 PHASE 2: CSS3 STYLING & MODERN VISUAL CRAFT (DAYS 6–11)
- [ ] **Day 06 — CSS Selectors, Colors & Typography:** Inline vs Internal vs External CSS, class vs ID specificity, Hex/RGB/HSL, `font-family`, Google Fonts, line-height, text styling.
- [ ] **Day 07 — The CSS Box Model (The #1 Exam Trap):** `content`, `padding`, `border`, `margin`, margin collapsing, `box-sizing: border-box` (The golden reset).
- [ ] **Day 08 — Display & Positioning:** `display: block / inline / inline-block / none`, `position: static / relative / absolute / fixed / sticky`, `z-index`.
- [ ] **Day 09 — Modern CSS Flexbox (The Superpower):** Flex container vs items, `flex-direction`, `justify-content`, `align-items`, `gap`, `flex-wrap`, centering elements in 2 lines.
- [ ] **Day 10 — CSS Grid & Responsive Media Queries:** `display: grid`, `grid-template-columns`, `fr` units, `@media (max-width: 768px)`, mobile-first layout design.
- [ ] **Day 11 — Visual Polish & Micro-Interactions:** `box-shadow` depth, `border-radius`, CSS transitions (`ease-in-out`), CSS transforms (`scale`, `rotate`, `translate`), subtle gradients.

---

### 🚀 PHASE 3: CAPSTONE & PRODUCTION BENCHMARK (DAYS 12–14)
- [ ] **Day 12 — Capstone Architecture & Wireframing:** Planning and structuring a sleek, real-world portfolio / product landing page with pure semantic HTML5.
- [ ] **Day 13 — Capstone Responsive Styling:** Styling the landing page with pure CSS3 (Flexbox + Grid + Dark Architectural palette + Mobile responsiveness).
- [ ] **Day 14 — Final Code Review, College Viva Simulation & Deployment:** Host live on GitHub Pages, test cross-browser rendering, and simulate professor viva exam questions.
